# Kaybolan Tek Çorabın Lahey Başvurusu

Bu yazılım, çamaşır makinesinde eşini kaybeden tek çorabın Uluslararası Adalet Divanı'na sunduğu dilekçeyi üretir.

Komik değildir. Çorap hukuku şakaya gelmez.

## Neden var?

Çünkü her evde bir çorap eksiktir ve hiç kimse bunu resmi evraka dökmemiştir. Artık dökülmüştür.

## Kurulum

```bash
python3 corap_davasi.py
python3 corap_davasi.py --renk "soluk gri" --beden "39" --taraf "sağ"
```

## Beklenen çıktı

Lahey usulüne uygun, tanıklı, talepli bir tutanak.

## Sorumluluk

Makine suçsuz çıkarsa çorap yine tek kalır. Yazılım bunu değiştirmez, sadece belgeler.
